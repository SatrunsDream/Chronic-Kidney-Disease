## RESULTS LOG

### ML_chronic_Kidney_disease-deploy.ipynb (pipeline)

Purpose:
- Load UCI CKD data, clean (rename columns, fix categoricals, map class to 0/1), handle missingness (MCAR → simple imputation).
- EDA: univariate distributions, correlation heatmap, bivariate violins and scatter by class.
- Preprocessing: label encoding, feature selection (chi-squared), train/test split.
- Models: KNN, Random Forest, XGBoost; hyperparameter tuning; confusion matrices and ROC curves.

Inputs:
- data/kidney_disease.csv
- data/data_description.txt

Outputs:
- Plotly HTML figures → docs/assets/ (via scripts/generate_assets.py)

Key findings:
- Serum creatinine, hemoglobin, blood urea, albumin, PCV, RBC differ strongly between CKD and non-CKD.
- Missingness treated as MCAR; imputation used.
- Best test performance: Random Forest (97% accuracy), then XGBoost (96%), then KNN (69%); KNN overfits (100% train, 69% test).
