# Predicting Chronic Kidney Disease

**By Sardor Sobirov**

A machine learning project that builds a prediction model for chronic kidney disease (CKD) using the [UCI Chronic Kidney Disease dataset](https://archive.ics.uci.edu/dataset/336/chronic+kidney+disease) (400 instances, 24 features). The workflow covers data cleaning, EDA, missingness analysis, feature selection, and three classifiers: KNN, Random Forest, and XGBoost.

## How to run

**If you already have the 12 Plotly HTML files** (e.g. in an `assets/` folder from the original notebook): copy them into `docs/assets/` so the storyboard can load them. You don’t need to run the script.

**If you need to regenerate the charts** (e.g. after a clean clone, or no assets yet):

1. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

2. **Generate storyboard assets** (writes the 12 HTML files into `docs/assets/`)
   ```bash
   python scripts/generate_assets.py
   ```

3. **Open the storyboard**  
   Open `docs/index.html` in a browser, or enable GitHub Pages from the `docs/` folder and visit the repo’s Pages URL.

**Deploying:** After generating assets, push the repo (including `docs/assets/*.html`). In **Settings → Pages**, set source to **Deploy from a branch** and choose the **docs** folder so the storyboard is served at your repo's Pages URL.

4. **Run the full notebook** (optional)  
   Open `ML_chronic_Kidney_disease-deploy.ipynb` and run all cells. Use paths `data/kidney_disease.csv` and `data/data_description.txt` if the notebook expects the repo root as the working directory.

## Results at a glance

- **Best test performance:** Random Forest (~97% accuracy), then XGBoost (~96%). KNN overfits (high train, ~69% test).
- **Key features:** Serum creatinine, haemoglobin, blood urea, albumin, packed cell volume, and related lab/clinical variables.
- **Missingness:** Treated as MCAR; random imputation (numeric) and mode (categorical) used before modeling.

For full methodology, interpretations, and figures, see the **storyboard** (`docs/index.html`) and `structure.md`.
