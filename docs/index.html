Introduction

A machine learning project using the UCI Chronic Kidney Disease dataset to predict CKD from clinical and lab features.

This project walks through building a prediction model for chronic kidney disease using a multivariate dataset from the UCI Machine Learning Repository. The data was collected from hospital records over about two months and includes 400 instances and 24 features—a mix of numerical lab values and categorical clinical indicators.

We clean the data, explore distributions and correlations, assess missingness, then train and compare three classifiers: K-Nearest Neighbors, Random Forest, and XGBoost. The goal is a clear, reproducible narrative you can scroll through section by section.

Dataset at a glance

Multivariate, classification task; 400 samples, 24 features.

Features include age, blood pressure, specific gravity, albumin, sugar, blood glucose random, blood urea, serum creatinine, sodium, potassium, haemoglobin, packed cell volume, white and red blood cell counts, plus categorical flags (e.g. hypertension, diabetes mellitus, coronary artery disease, appetite, pedal edema, anemia) and the binary target: ckd vs not ckd.

Correlation heatmap

How numeric features relate to each other.

Notable patterns: positive links between specific gravity and red blood cell count / packed cell volume / haemoglobin; sugar with blood glucose random; blood urea with serum creatinine; and haemoglobin with PCV and RBC. Negative correlations appear between albumin and blood urea vs RBC/PCV/hemoglobin, and between serum creatinine and sodium—consistent with kidney function and fluid balance.

Missingness and preprocessing

Missing data was treated as MCAR and handled with random imputation (numeric) and mode (categorical).

Tests across columns suggested missingness was not strongly dependent on other observed variables (MCAR). We used random-value imputation for numeric columns and mode imputation for categorical ones, then label-encoded categoricals. Feature selection was done with chi-squared (SelectKBest); the top 10 features were used for modeling.

Models and evaluation

KNN, Random Forest, and XGBoost—confusion matrices and ROC curves.

We compare three classifiers on the same train/test split (75% train). KNN reached high training accuracy but only ~69% test accuracy (signs of overfitting). Random Forest achieved ~97% test accuracy with strong precision and recall for both classes. XGBoost reached ~96% test accuracy with balanced metrics. Summary

Random Forest and XGBoost generalize well; KNN overfits.

Serum creatinine, haemoglobin, blood urea, and related lab and clinical features drive the predictions. Random Forest and XGBoost both achieve high test accuracy (97% and 96%) and are suitable as reference models for this dataset. The full pipeline—from cleaning and EDA through feature selection and tuning—is reproducible via the notebook and scripts/generate_assets.py, which regenerates the Plotly figures in docs/assets/.
